# tidykeep 协议（本项目 Agent 规则入口）

> 本项目启用 tidykeep：一套防止旧代码、旧文档、旧设计残留的工作协议。
> **本文件是所有 AI Agent（Claude Code / Codex / Kimi / Gemini 等）的唯一规则入口。**
> 违反协议的操作会被 hooks 拦截（Claude Code 层 + git 层）。

## 三个核心文件

| 文件 | 作用 | 谁维护 |
|---|---|---|
| `AGENTS.md`（本文件） | 规则入口，长期稳定 | 人 |
| `STATE.md` | **当前设计的唯一真相** + 决策记录 + 已废弃墓地 | Agent 每次设计变更时 |
| `LEDGER.md` | 每个受管代码/文档文件的 TODO / DONE 台账 | Agent 每次任务收尾时 |

## 任务循环协议（每次任务必须遵守）

**开工前：**
1. 读 `STATE.md`，以其中"当前架构与设计"为唯一事实依据。
2. 读 `LEDGER.md` 中与本次任务相关文件的条目，了解该文件的 TODO 与历史。
3. **禁止**参考 `STATE.md` 墓地中已废弃的方案，禁止复活已删除的旧实现。

**干活时（文件规则）：**
- 优先修改现有文件。**禁止**创建 `xxx_v2` / `xxx_old` / `xxx_new` / `xxx_final` / `xxx_backup` / `xxx copy` 等历史副本命名的文件（hook 会直接拦截并要求改名）。
- 只是参数不同时，用命令行参数或配置文件，而不是复制脚本。
- 一次性 / 实验 / 验证脚本统一放**项目内**草稿区 `.tmp/`（已 gitignore），在那里创建并执行。
  **禁止**写入系统 `/tmp`、`~/tmp`、`~/.tmp`、`$TMPDIR`（hook 会拦截并要求改路径）——
  系统临时目录里的残留无人管理。脚本完成使命后**立即删除**（Stop hook 会检查残留）。
- 不再使用的文件要**删除**（历史在 git 里，随时可找回），并在 `STATE.md` 墓地登记：删了什么、为什么、被什么取代。
- 文档必须反映现状：发现过期段落，要么当场更新，要么删除并在墓地登记。禁止写"新版方案""临时做法"这类必然腐烂的措辞。

**收尾时（三件事，缺一不可，Stop hook 与 pre-commit 会检查）：**
1. **更新 `LEDGER.md`**：本次完成的条目从 TODO 移入 DONE（附日期）；新发现的待办登记进 TODO；刷新相关文件的"最后核对"日期。
2. **同步 `STATE.md`**：若设计/架构/接口有变化，更新"当前架构与设计"，并把被取代的决策标记为 `superseded → 新决策`；删除的文件登记进墓地。
3. **详细提交**：按下方 Commit 规范提交（commit-msg hook 会校验）。

附加自检：`.tmp/` 中已完成使命的临时/验证脚本要删除；确需跨任务保留的，向用户说明原因。

## Commit 规范

```
<type>: <一句话说清做了什么>

为什么: <动机 / 修复的问题 / 对应的 TODO>
影响: <涉及的模块与文件；台账/状态文件相应更新点>
```

- `type` ∈ feat / fix / refactor / docs / chore / test / perf。
- 主题行与正文都不得敷衍（有最小长度校验）。合并 / revert / fixup 提交自动豁免。
- 确属琐碎改动可用 `TIDYKEEP_SKIP=1 git commit ...` 跳过校验，但必须在对话中向用户说明原因，不得默默绕过。

## 与 hooks 的关系

- Claude Code：`PreToolUse` 拦截历史副本命名的新建、以及在系统临时目录落盘（重定向到 `.tmp/`）；`Stop` 在台账未同步或 `.tmp/` 有残留时阻止收工（每会话强制一次）。
- 所有 Agent 与人类：git `pre-commit` 拦截垃圾命名文件入库、检查台账同步；`commit-msg` 校验提交信息。
- 误报处理：把路径加入 `.tidykeep/allowlist`（每行一个精确路径）。配置见 `.tidykeep/config`。

## 深度操作

初始化扫描、体检审计、收尾同步的完整流程见技能文件 `.claude/skills/tidykeep/SKILL.md`。
非 Claude Code 的 Agent 直接说"按照 AGENTS.md 的 tidykeep 协议执行初始化扫描 / 审计 / 收尾同步"，并阅读该技能文件后照做。
