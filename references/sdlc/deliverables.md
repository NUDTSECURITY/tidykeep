# 交付物体系

本文档定义 SDLC 各阶段的交付物、格式与存放路径。

## 产品阶段交付物

| 交付物 | 格式 | 存放路径 |
|---|---|---|
| PRD | Markdown | `/产品文档/项目名-PRD.md` |
| MRD（可选） | Markdown | `/产品文档/项目名-MRD.md` |
| 流程图 | Mermaid / 文字描述 | 嵌入 PRD |

## 开发阶段交付物

| 交付物 | 格式 | 存放路径 |
|---|---|---|
| 技术设计文档 | Markdown | `/产品文档/项目名-技术设计.md` |
| 源代码 | 按项目技术栈 | 项目目录 |
| 数据库设计 | Markdown / SQL | `/产品文档/项目名-数据库设计.md` |
| 模块技术文档 | Markdown | `/产品文档/technical/模块名.md` |

## 测试阶段交付物

| 交付物 | 格式 | 存放路径 |
|---|---|---|
| 质量验证报告 | Markdown | `/产品文档/项目名-测试报告.md` |
| 功能测试方案（POC） | Markdown / docx | `/产品文档/项目名-功能测试方案.md` |
| 动态功能测试执行记录 | Markdown | `/产品文档/项目名-动态测试记录.md` |

## 文档维护阶段交付物

| 交付物 | 格式 | 存放路径 |
|---|---|---|
| 技术文档入口 | Markdown | `/产品文档/technical/quickstart.md` |
| 架构总览 | Markdown | `/产品文档/technical/architecture.md` |
| 文档维护报告 | Markdown | `/产品文档/项目名-文档维护报告.md` |
| 项目根文档引用 | Markdown | `README.md` 或 `AGENTS.md` |

## 文档规范

- 所有文档结构清晰、可独立理解
- 版本更新使用 `v2`、`v3` 等标识
- 多文档时先输出目录索引
